# QHR 加班助手

基于 C#、.NET 8 和 WPF 的 QHR 打卡统计工具。程序使用公司账号向 SSO 获取当前会话 token，再建立 QHR 会话读取打卡流水；不需要打开浏览器。启用自动登录后，密码由 Windows 凭据管理器加密保管，不会写入程序配置文件，token 始终只保存在当前进程。

## 功能

- 按每日、月度、年度汇总加班时间和预估加班费。
- 概览使用月历展示每日加班时长和加班费，并提供上个月、下个月、本月快捷切换；点击日期可查看首末卡、请假/延时抵扣、餐补和当天费用详情，填写备注并保存加班证据图片，当前月自动禁用“下个月”。
- 修改统计日期或切换月份后自动防抖读取本地档案，无需手动点击刷新；本地已有整月数据时不联网、也不显示刷新遮罩。
- 程序启动时更新一次本月和上月，头像菜单的“刷新数据”可主动再次更新；查看其他月份只在本地整月为空时联网补取该月份，同一运行会话内每月最多自动尝试一次。空响应或部分响应不会删除既有本地数据。
- 升级到请假审批同步版本时会执行一次历史请假迁移：仅读取已完成审批并补入现有加密档案，不重抓历史打卡；完成后仍只更新本月和上月。
- 独立“分析汇总”页面支持单个年度、近三年、近五年和近十年分析，不受概览所选月份影响；月度图合并对比加班费与餐补次数，并按工作日、周末、节假日展示加班时长构成。
- 每日备注与证据图片使用 Windows DPAPI 独立加密，按“年/月/日/单图”分片保存并按需加载；每张图片限制 20 MB、每天限制 30 张，避免考勤主档案和单个数据文件无限膨胀。
- 当天详情可一键导出单日 ZIP；月历也可一键导出整月 ZIP，包含 Excel 可直接打开的月度 CSV，以及各天的计算明细、备注和原始证据图片，便于报销、留档或发送。
- “加班目标”页面按起算日后的累计加班收入追踪购买目标，可选择只计算加班费或计算加班费与餐补；消费记录会减少实际有效金额，目标和消费使用 Windows DPAPI 加密保存。
- 默认费率：工作日 20 元/小时、周末 30 元/小时、节假日 60 元/小时，均可在界面修改。
- 后台自动同步中国法定节假日与调休工作日，在线失败时使用本地缓存；同步及加密档案状态统一显示在概览，节假日直接在月历中用特殊颜色标记。
- 自动读取 QHR 月度考勤汇总及状态为“完成”的“请假申请”；同一天取两种来源的较大值去重，再从当月加班时数中抵扣。
- 自动读取状态为“完成”的“延时工时扣减申请”，按申请发生日期和 `AMOUNT` 分钟数优先抵扣当天加班；抵扣部分不计算加班费，也不参与餐补门槛。
- 获取后的打卡、请假/缺勤、餐补次数和班次快照会使用 Windows DPAPI 加密保存；QHR 清空历史字段或暂时不可访问时自动使用本地档案补回。
- 支持配置弹性上班窗口、标准在岗跨度、工作日起算时间、餐补门槛、最小加班时长和取整粒度。
- 支持 SSO 账号密码登录，以及已有 QHR Token 的高级登录方式。
- 支持通过 Windows 凭据管理器自动登录，主动退出账号时自动清除凭据。
- 当前版本为 1.2，头像菜单提供“检查更新”；支持远程 `update.json` 清单或程序目录本地清单。
- 内置 WebView2 QHR 请求诊断窗口，可从右上角头像菜单打开；支持脱敏记录请求与 JSON 响应并导出。

## 默认计算规则

- 工作日：08:30–09:30 弹性上班，标准在岗跨度 9 小时；默认从 19:00 起算到末卡。
- 周末/节假日：从首卡到末卡直接计算，不扣除午休或晚餐。
- 请假抵扣：按月汇总 QHR 已结算的请假/缺勤和已完成的请假审批，优先抵扣工作日加班，再抵扣周末和节假日；当天未结算的临时缺勤值不会参与抵扣。
- 延时工时抵扣：仅同步审批状态为“完成”的申请，按分钟换算成小时后先从当天原始加班扣除，再进行月度请假抵扣。
- 餐补：工作日加班满 1 小时补贴 20 元；周末或节假日满 4 小时补贴 20 元。餐补金额和门槛均可配置。
- 默认最小加班时长为 0，所有完整分钟都参与计费；餐补仍分别使用工作日 1 小时、周末/节假日 4 小时门槛。
- 节假日 JSON 中 `isOffDay=true` 的日期按节假日费率；`isOffDay=false` 的调休日期按工作日费率；其余周六、周日按周末费率。

这些规则都可在“计算设置”页面调整。结果依据打卡跨度计算，仅作为个人估算，不替代审批记录或工资单。

## 构建与运行

```powershell
dotnet build QHR.csproj -c Release
dotnet run --project QHR.csproj
```

需要 Windows 10/11 和 .NET 8 Desktop Runtime。访问 SSO 与 QHR 时需要能够连接公司网络。

如需直接打开诊断浏览器：

```powershell
.\QHR.Overtime.exe --capture
```

诊断浏览器需要 Microsoft Edge WebView2 Runtime（Windows 10/11 通常已预装）。

生成可直接分发的 Windows x64 自包含 ZIP（目标电脑无需安装 .NET 8）：

```powershell
.\Tools\Publish-Package.ps1
```

生成结果位于 `artifacts\QHR.Overtime-win-x64-Release.zip`，解压后运行 `QHR.Overtime.exe`。

## 数据位置

配置、节假日缓存和加密考勤档案位于：

```text
%LOCALAPPDATA%\QHR.Overtime\
```

考勤档案和目标账本位于其中的 `secure` 目录，按 QHR 账号隔离，并通过 Windows DPAPI 绑定当前 Windows 用户，文件本身不是可读 JSON。密码与会话 token 不写入该目录；自动登录密码保存在当前 Windows 用户的凭据管理器中。节假日默认使用 [NateScarlet/holiday-cn](https://github.com/NateScarlet/holiday-cn) 的全年 JSON，可在设置中替换为兼容地址。

脱敏后的 QHR 诊断文件保存在 `%LOCALAPPDATA%\QHR.Overtime\captures\`。
